# Store Release Metadata

Use this checklist before publishing production builds to Play Store/App Store.

## Android Play Store
- App name: NewsApp
- Short description: Hyperlocal and real-time news in your language.
- Full description: Daily personalized news, breaking alerts, weather, shorts, bookmarks, and AI-assisted summaries.
- Category: News & Magazines
- Contact email: support@newsapp.example
- Privacy policy URL: https://newsapp.example/privacy
- Target countries/languages: define per release rollout plan

## iOS App Store
- App name: NewsApp
- Subtitle: Local and breaking news
- Promotional text: Stay updated with local, national, and global stories.
- Keywords: news,breaking,local,weather,shorts,bookmark
- Support URL: https://newsapp.example/support
- Marketing URL: https://newsapp.example
- Privacy policy URL: https://newsapp.example/privacy

## Release Notes Source
- Keep end-user change notes aligned with `flutter_app/CHANGELOG.md`.
- For each store upload, copy highlights from the current release section.
- Include at least one bug fix and one user-facing improvement in notes.
